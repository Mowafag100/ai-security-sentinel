# 🛡️ AI Security Sentinel

An advanced AI-powered security auditor designed for resource-constrained environments. This tool integrates **Bandit** (Static Analysis) with **TinyLlama** (LLM) to provide real-time vulnerability detection and AI-driven remediation plans.

## 🚀 Why this project?
Built as a practical application of Edge AI, this sentinel runs entirely on a mobile environment (Termux/Android), proving that high-level security auditing doesn't require massive cloud resources.

## 🛠️ Tech Stack
- **AI Model:** TinyLlama-1.1B (via Ollama)
- **Backend:** FastAPI (Python 3.13)
- **Security Engine:** Bandit
- **UI:** Tailwind CSS & JavaScript

## 🧠 Challenges Overcome
- **RAM Optimization:** Successfully deployed a functional LLM on a device with limited memory by switching to TinyLlama.
- **Environment Bridging:** Solved isolation issues between Linux (Termux) and Android storage for seamless file uploads.
